KURZE ANLEITUNG

So nutzt du das Cockpit

1

Ist-Werte erfassen

Öffne Avinox Ride und lies die aktuell eingestellten Motorwerte ab. Miss Gabel-/Dämpfer-SAG und die Reifenluftdrücke. Trage nur wirklich überprüfte Werte in „Mein Bike“ ein.

2

Mit den beiden Empfehlungen vergleichen

Waldtrail ist auf gemischte Waldtrails ausgelegt; Allgäu Berge auf längere Anstiege und alpine Schotterpassagen. Du kannst alle Profilwerte bearbeiten und ihre Originalvorschläge bei Bedarf zurücksetzen.

3

Eine Veränderung testen

Übertrage die gewünschten Parameter manuell in die Avinox Ride App bzw. stelle das Fahrwerk ein. Notiere danach die tatsächlichen Ist-Werte und protokolliere unter „Testfahrten“ die Runde samt Höhenmetern, Verbrauch und Fahreindruck.

4

Auf allen Geräten verwenden

GitHub Pages veröffentlichen, Repositoryname im Reiter „Speichern & GitHub“ angeben, von GitHub laden und mit einem fine-grained personal access token dort speichern. Auf einem zweiten Gerät dieselbe GitHub-Pages-URL öffnen und zuerst „Von GitHub laden“ klicken.

GitHub Pages einmalig einrichten

  1. Neues Repository anlegen (z. B. amflow-px-setup) und die Dateien des ZIP-Hauptordners hineinladen.
  2. Unter Settings → Pages die Quelle Deploy from a branch, main und /(root) auswählen.
  3. Die GitHub-Pages-Adresse öffnen und unter „Speichern & GitHub“ Nutzernamen und Repository eintragen.
  4. Für das Schreiben auf GitHub einen Fine-grained personal access token anlegen: nur dieses Repository auswählen, Berechtigung Contents: Read and write aktivieren. Token im Cockpit eingeben und „Auf GitHub speichern“ nutzen.
  5. Später auf jedem Gerät zuerst „Von GitHub laden“, dann Änderungen vornehmen, anschließend „Auf GitHub speichern“.
Wichtig: Bei einem öffentlichen GitHub-Repository ist auch die Datei data/bike-setup.json öffentlich einsehbar und in der Commit-Historie nachvollziehbar. Keine privaten Notizen oder Zugangsdaten eintragen. Wenn du wirklich private Daten speichern willst, ist eine private Backend-Lösung besser geeignet.

Quellen zur Funktionslogik: Avinox-Bedienungsanleitung 2026 · GitHub Contents API. Die zwei Abstimmungen sind persönliche Startempfehlungen und keine freigegebenen Hersteller-Setups. Bitte nur zulässige Einstellungen verwenden.
