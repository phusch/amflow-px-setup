SUPABASE-SERVERFREIGABE (einmalig)
=================================

Im bestehenden Supabase-Projekt `huschel-speicher-pilot` unter
Edge Functions → github-app-storage → Code → index.ts

Im bereits existierenden Objekt `const APPS` genau eine Zeile ergänzen:

  "amflow-px-setup": "amflow-px-setup/data.json",

Beispiel (Auszug, alle bisherigen Einträge behalten):

const APPS: Record<string, string> = {
  "chillout-lab": "chillout-lab/data.json",
  "tour-navigator": "tour-navigator/data.json",
  // ... andere Einträge NICHT löschen ...
  "amflow-px-setup": "amflow-px-setup/data.json",
};

Danach `Deploy updates` klicken.

WICHTIG: KEINEN alten kompletten Edge-Function-Code deployen, denn das
könnte neuere Freigaben und Sicherheitsänderungen überschreiben.
GitHub-Token, UID-Prüfung, JWT-Einstellungen und alle vorhandenen App-IDs
bleiben unverändert. Das private Repository ist phusch/huschel-app-data.
